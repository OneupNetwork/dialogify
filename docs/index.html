Getting Started

Include script in your HTML document.

<script src="path/to/jquery.js"></script>
<script src="path/to/dialogify.min.js"></script>

Disable Css Injection

所有樣式跟圖片都塞進 js 了，不用另外載入 css
要自訂樣式的話（像是暗色版），將 id="dialogifyCss" 的 css 放在 js 前
不然 inject css 是 inline 形式，優先權比 css 檔案高

<link href="path/to/dialogify.css" id="dialogifyCss" rel="stylesheet" type="text/css">

beforeclose 事件

beforeclose 會在所有關閉途徑之前觸發（按鈕、右上關閉、esc、點背景、form 送出、close()）， 呼叫 preventDefault() 就可以留住燈箱： 

dialogify.on('beforeclose', async function(e){
    if(isDirty) {
        e.preventDefault();
        if(await Dialogify.confirm('確定要放棄編輯嗎？')) {
            isDirty = false;
            dialogify.close();
        }
    }
});
drawer（側邊滑出）

設定 position 就會從指定邊緣滑入，而不是置中顯示：

new Dialogify('<h4>篩選條件</h4>', {position: Dialogify.POSITION_RIGHT}).showModal();
// position: 'left' | 'right' | 'top' | 'bottom'

只有點到 drawer 以外的區域（背景遮罩）才會關閉，點 drawer 內部沒有內容的地方不會誤關。

動畫

drawer 從邊緣滑入滑出、toast 淡入淡出並帶縮放、popover 淡入淡出。 離場動畫是在燈箱關閉後才播放，所以有 autoRemove 的燈箱會等動畫結束才從 DOM 移除。 關閉中的 toast 會同步把自己的高度收合起來，堆疊在下面的 toast 才不會在它被移除的瞬間跳一下。 使用者若開啟 prefers-reduced-motion: reduce，這些動畫都會自動停用。

<dialog is="bahamut-dialogify">

除了用 JavaScript 建立燈箱外，也可以直接把燈箱寫在 HTML 裡。載入 dialogify 後會自動註冊 customized built-in element， 用 document.querySelector() 取到的元素本身就有 dialogify 的 public method。

元素名稱有前綴是因為 custom element 規格要求名稱必須含連字號，is="dialogify" 不是合法名稱。

和 new Dialogify() 不同，宣告式燈箱關閉後不會從 DOM 移除，可以重複開啟。 

<dialog is="bahamut-dialogify" dialog-title="Dialogify">
    dialog content <b>bold text</b>
    <button ok></button>
    <button cancel></button>
</dialog>

<script>
const dialog = document.querySelector('dialog[is="bahamut-dialogify"]');
dialog.showModal();
</script>

Options (attribute)

⚠️ 屬性值是字串，所以布林設定是看值而不是看有沒有這個屬性：要關閉請寫 closable="false"，只寫屬性名稱、"true" 或其他值都代表 true， 這和 HTML 原生布林屬性的慣例相反。

dialog-title 燈箱標題（title 是原生 tooltip，所以改用 dialog-title）
size size="large" 對應 Dialogify.SIZE_LARGE，其他值直接當 class 使用
closable 是否顯示關閉按鈕
fixed 是否使用 position: fixed
background-scroll 燈箱開啟時是否允許背景捲動
use-dialog-form 是否用 <form method="dialog"> 包住內容
src 改用 ajax 載入內容，不使用標籤內的 html
ajax-prefix 同 dialogOptions.ajaxPrefix
position left | right | top | bottom，設定後變成 drawer 樣式
anchor 錨定元素的 CSS selector，設定後呼叫 showAt() 可以不用傳參數
placement 錨定方向：top | bottom | left | right（預設 bottom）
align 錨定對齊：start | center | end（預設 start）
offset 錨定元素與燈箱的間距，單位 px（預設 8）
options='{...}' 用 JSON 一次設定多個 options
buttons-position 按鈕對齊：left | center | right（預設 right）

無法用屬性表示的設定（callback、style 物件）可以在第一次開啟前用 JavaScript 指定：

dialog.options = {ajaxComplete: function(){ /* ... */ }};
Buttons

在燈箱內容裡直接放 <button> 並加上標記屬性，dialogify 會把它們收集成按鈕列， 結構和用 JavaScript 的 buttons() 產生的一樣。按鈕沒有文字時會自動帶入對應語系的預設文字。

⚠️ 請寫 <button ok></button>，不要寫 <button ok />。 HTML 元素沒有自閉合語法，那樣寫會讓後面的兄弟元素被解析成它的子元素。

ok primary 樣式，點擊後關閉燈箱
cancel 預設樣式，點擊後觸發 cancel 事件並關閉燈箱
close 預設樣式，點擊後關閉燈箱
primary primary 樣式，不會自動關閉
danger danger 樣式，不會自動關閉
id / loading-text 寫在 html 的按鈕也會加入 $buttonList，有 id 就用 id 當 key，沒有就用順序
loading-text 是按鈕 loading 時要顯示的文字 
<dialog is="bahamut-dialogify">
    確定要刪除嗎？
    <button cancel></button>
    <button danger onclick="doDelete()">刪除</button>
</dialog>
// 寫在 html 的按鈕一樣可以用 JavaScript 控制
dialog.updateButton('save', {loading: true});
Events

close、cancel 是 <dialog> 的原生事件，show、beforeclose 由 dialogify 發送，都可以用一般方式綁定： 

dialog.addEventListener('show', function(){});
dialog.onshow = function(){};
dialog.onclose = function(){};

// beforeclose 可以攔下關閉動作
dialog.addEventListener('beforeclose', function(e){ e.preventDefault(); });
dialog.onbeforeclose = function(){ return false; };

也可以寫在標籤上。onclose、oncancel 是原生 inline handler，行為就是瀏覽器定義的那樣； 除此之外 dialogify 會把 onshow、onclose、oncancel、onbeforeclose 的值當成函式名稱解析： 

<dialog is="bahamut-dialogify" onshow="myHandler" onclose="MyApp.onClose"></dialog>
Dialogify.handlers.myHandler = function(){
    // this 是燈箱元素
};

名稱會先找 Dialogify.handlers，再找 window（支援 A.b.c 這種路徑）， 而且是在事件發生時才解析，所以 handler 可以晚於標籤定義。值如果不是單純的識別字就會被 dialogify 忽略， 交給瀏覽器原生的 inline handler 處理 —— dialogify 本身不會執行任何字串程式碼。

Browser support

Safari/WebKit 不支援 customized built-in elements，需要在 dialogify 之前載入 @ungap/custom-elements 才能使用宣告式寫法。dialogify 有附一份打包好的選用檔案： 

<script src="path/to/custom-elements.min.js"></script>
<script src="path/to/dialogify.min.js"></script>
import '@oneup_network/dialogify/custom-elements';
import Dialogify from '@oneup_network/dialogify';

已經支援的瀏覽器載入它不會有任何作用，JavaScript API 則本來就不受影響。

Example - beforeclose, loading & form
const dialogify = new Dialogify('#demo12_template')
    .title('編輯文章')
    .buttons([
        {type: Dialogify.BUTTON_DEFAULT, text: 'Cancel'},
        {id: 'save', type: Dialogify.BUTTON_PRIMARY, text: '儲存', click: onSave}
    ]);

// 儲存中不讓它關（esc、點背景、關閉鈕都擋得住）
dialogify.on('beforeclose', function(e){
    if (this.isLoading()) e.preventDefault();
});

async function onSave(e){
    e.preventDefault();                       // 擋掉 dialog form 的自動關閉
    if (!dialogify.validate()) return;        // 原生表單驗證

    dialogify.setLoading(true);
    dialogify.updateButton('save', {loading: true, loadingText: '儲存中...'});
    await save(dialogify.formValues());       // {title: '...', content: '...'}
    dialogify.setLoading(false);
    dialogify.updateButton('save', {loading: false});

    dialogify.close();
    Dialogify.toast('已儲存', {type: 'success'});
}

dialogify.showModal().then(function(returnValue){
    console.log('closed with', returnValue);  // show()/showModal() 回傳 promise
});

        Dialogify.alert('No, I don\'t');
    }
});

// same as
async function() {
    if(await Dialogify.confirm('Do you like Dialogify ?')) {
        Dialogify.alert('Yes, I do');
    } else {
        Dialogify.alert('No, I don\'t');
    }
}

Dialogify.prompt(message, options)

message: string
message html text
options: {}, optional
placeholder string
輸入框的 placeholder，可省略
value string
輸入框的預設 value，可省略
ok function
按確定時呼叫，this 是 dialogify object，沒特別動作可省略
cancel function
按取消時呼叫，this 是 dialogify object，沒特別動作可省略
dialogOptions object
see dialogOptions above 

Dialogify.prompt('What\'s your name ?', {
    placeholder: 'Enter your name',
    ok: function(val){
        Dialogify.alert('Hi! ' + val);
    },
    cancel: function(){
        Dialogify.alert('canceled');
    }
});

// same as
async function(){
    const name = await Dialogify.prompt('What\'s your name ?', {
        placeholder: 'Enter your name'
    });

    if (name != null) {
        Dialogify.alert('Hi! ' + name);
    } else {
        Dialogify.alert('canceled');
    }
}

Dialogify.toast(message, options)

顯示會自動消失的輕量提示，不會擋住使用者操作，同一角落的 toast 會自動往下堆疊。

Dialogify.toast('儲存成功', {type: 'success'});

Dialogify.toast('連線失敗，請稍後再試', {
    type: 'error',
    duration: 5000,
    position: Dialogify.TOAST_BOTTOM_CENTER
});

// duration: 0 代表不自動關閉，要自己收
const toast = Dialogify.toast('處理中...', {duration: 0, closable: true});
toast.close();
options: {}, optional
type info | success | warning | error
預設 info，決定 toast 的配色
duration number
預設 3000 毫秒；設 0 則不自動關閉
position Dialogify.TOAST_TOP_RIGHT | TOAST_TOP_LEFT | TOAST_TOP_CENTER | TOAST_BOTTOM_RIGHT | TOAST_BOTTOM_LEFT | TOAST_BOTTOM_CENTER
預設右上角
closable true | false
預設 false，設 true 會顯示關閉鈕
onClose function，toast 關閉後呼叫

回傳的物件有 close() 和 dialog（toast 的 DOM 元素）。 message 和其他 API 一樣會當成 html 解析，帶入使用者輸入時請先做逸出處理。
